## Shared height interpretation

The owner clarified the intended progression on November 11, 2026:
**pawn < rook < knight < bishop < queen < king**, with the queen relatively
close to the king. Chavet and Lardy examples are useful visual guides to this
relationship. This records a proportion preference, not evidence of authorship
or a universal claim about those manufacturers or historical Staunton sets.
The original Lichess images settle reference conflicts. Keep existing gallery
defaults until a separate sizing decision; changes to one piece must not
silently rescale the others. Generated side images remain interpretations.

# Bishop side-view guide

`side-01.png` was generated with the built-in image tool from the original white Lichess bishop and selected White 3 enlargement. The user approved it as the side-profile art direction, especially the continuous curved head meeting the shallow button without an exposed neck. It is an imagined view, not evidence of the original 3D model. Original sprites remain the historical source. The exact prompt, source/output hashes and approval are in `side-01-generation.json`.

`side-01-cutout.png` is the transparent AI extraction used by the whole-set gallery. `side-01-cutout-generation.json` records its exact prompt and source/output hashes. The extraction also altered some surface texture/framing; `side-01.png` above remains the untouched generated guide. Gallery scaling uses measurements of the cutout, not the original framing.

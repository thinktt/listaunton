# Rook checkpoint 021 — accepted foot reflector

Adds a 40 W rectangular, glossy-only light linked to the foot region. It makes the thin lower crescent clearer without the grain regressions of the preceding repair studies. The 120 W and 300 W versions become overly solid white stripes and are rejected. This is a modest local improvement, not a complete match.

The previous accepted model and assets are archived in history/rook-mission-004. Editable and evaluated control geometry, fixed 54-degree camera, original material nodes/packed pixels, world and existing lights are exact. Four derived receivers retain all 30,832 surface faces exactly once, at identical positions. Re-evaluated Boolean UVs vary by at most 5.9604645e-8 (under 0.0002 atlas pixel); copied normal encoding differs by at most 0.000472665 per component. Initial exact-byte UV checks failed and their logs are retained. The scoped validator now separates exact position/coverage from measured UV/normal precision. It does not claim bit-exact derived normals or UVs.

The saved candidate was reopened and rendered. Final staged model was also reopened, validated and rendered in fixed/profile/rear views. The viewer exports the closed editable control, not the open receiver partitions, with the same atlas and camera. Runtime harness passes wood/clay switching, side registration, orbit/pan/zoom, reset, reference endpoints and tab persistence; maximum sampled camera discrepancy is 0.00003644 pixel. This is a harness check, not a native browser GPU visual test. Site integration and candidate interaction checks passed. Existing Windows preview and repository files match by SHA-256 in preview-sync.json. No push or publication.

Measured outline: selected 97.30350%, original 95.67335%. Subjective interior/color/grain/lighting: 78/76/66/45; working mean 72.46%, holistic still 60-70%. Remaining defects include shoulder blobs, weak turret crescents, inside-wall artifacts, baked pigment lighting and side-neck texture transitions. Original source images, selected candidate and gallery defaults are preserved. Goal remains active.

Reproduce this trial with scripts/rook/foot_light_study.py using the archived checkpoint 004; validate with validate_foot_checkpoint.py. stage_foot_checkpoint.py prepares a separate root; export_mission.py exports its closed control; build_side_comparison.py and build_viewer.py rebuild the review. render_regions.py verifies derived receiver coverage and precision. Geometry edits require regenerating receivers before rendering or acceptance. Do not run the original neutral builder over this checkpoint.

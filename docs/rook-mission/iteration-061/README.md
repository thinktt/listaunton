# Upper-patch correspondence

Rasterized the evaluated closed-body UV triangles into the fixed orthographic camera. 32,895 atlas texels mapped, none multiply covered. Independent ray probes agree within 0.280 display pixels. Diagnostic only; no new model or score. Reproduce with scripts/rook/map_upper_patch.py. The map is restricted to a front-facing patch and is not a general occlusion-aware atlas projector.

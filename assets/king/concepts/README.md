# King side-view guide

`side-01.png` is an imagined, nearly level elevation generated with the built-in image tool from the original black Lichess king and selected Black candidate 1 enlargement. It is a candidate for discussing proportions, not yet an owner-approved modeling target. The current king and its camera variants are unchanged.

The original sprite remains the historical design source. Its cross tip is clipped; the generated side view conservatively completes that upper arm. Hidden geometry, exact vertical dimensions and the side-view camera are inferred. The image does not establish the original artist or model.

The exact prompt, unchanged input hashes and output hash are recorded in `side-01-generation.json`.

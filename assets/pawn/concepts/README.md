# Pawn side-view guide

`side-01.png` was generated with the built-in image tool from the original black Lichess sprite and the selected high-resolution reference. It is an imagined side elevation for discussing proportions, not recovered original geometry or a calibrated camera view. This candidate has not yet been selected as a modeling target; existing models and selected references are unchanged.

The exact prompt and input/output hashes are in `side-01-generation.json`. View it with the other pieces in the whole-set page’s **Side views** tab.

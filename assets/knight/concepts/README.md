# Inferred knight side view

`side-01.png` was generated with the built-in image-generation tool from both original knight sprites and selected black candidate 2. The exact prompt, source paths and SHA-256 hashes are recorded in `side-01-generation.json`.

The project owner endorsed this interpretation as a modeling guide and requested a more conical muzzle. It is supplementary anatomical guidance for the profile; it does not replace the selected high-resolution reference or the authoritative Lichess originals. Base proportions and unseen details in this imagined view are not recovered evidence.
